# GitHub Actions Implementation Plan

> **For agentic workers:** Execute in the current session. A focused helper task may run independently under the dispatching-parallel-agents skill; preserve file ownership and use one final review.

**Goal:** Ejecutar la suite completa al subir código y publicar imágenes/versiones automáticamente desde main si pasa.

**Architecture:** Workflow de validación de solo lectura y job de publicación dependiente. Helper Git/Python para versión y metadatos; BEDCA fijado por commit/checksum; candidatos inmutables y promoción posterior a verificación.

**Tech Stack:** GitHub Actions, Python 3.14, uv, Docker Buildx/QEMU, GHCR, Git.

**Spec:** [Diseño](../specs/2026-11-02-actions-design.md).

## Global Constraints

- Primera versión 1.0.0; excluir v1.13.0 histórica. No alterar contratos de aplicación.
- Toda la suite Docker debe ejecutarse; no utilizar claves OpenAI ni Mealie del usuario.
- Publicar solo main propietario, después de validar, con GITHUB_TOKEN.
- No force push, doble incremento por reintento ni rollback de latest por ejecuciones antiguas.
- Mantener condiciones y originales de BEDCA.

## Review Focus

- Un tag legado no debe elevar la versión a 1.13.x.
- Un reintento o fallo parcial debe conservar la versión y el último artefacto válido.
- Un push concurrente no debe publicar una revisión antigua como la más reciente.
- Los PR externos no deben recibir permisos de escritura ni secretos.
- El CSV incorrecto o ausente y una prueba Docker omitida deben detener la publicación.
